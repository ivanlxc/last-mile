# LAST MILE 团队交付导览

本资料包把平民转运、人机信任校准与来源核验落实到一张连续地图、三幕故事及可实现的事件数据。它是游戏开发资产与设计蓝图，尚不是可运行的完整游戏。

## 建议阅读顺序

1. **01_全景沙盘.png / 02_俯视路线图.png**：先看世界、区域和主支路线。
2. **地图设计与资产接入.pdf**：8 页地图手册，说明地区、路线、集合、坐标和导入方式。
3. **LAST_MILE_故事与游戏设计.md**：完整背景、20 位乘员、开场与三幕逐拍剧情、28 条证据、行动后果、四种结局呈现、资源、评分、AI 边界和开发验收。
4. **比赛对齐与48小时计划.md**：官方页面核查、参赛主题建议、信息冲突、48 小时分工和 2 分钟 Pitch。

## 程序与美术文件

| 文件 | 用途 |
| --- | --- |
| LAST_MILE_Master.blend | 可编辑母版，保留底座、地图说明层、5 台相机、灯光、可切换事件烟雾。 |
| LAST_MILE_GameMap.glb | 通用场景资产，包含地形、建筑、车辆、道路与命名热点；排除底座、摄影棚、演示标签及烟雾。 |
| last_mile_map.json | 11 个节点、13 条路线、26 个一致的端点，两套坐标与移动时长。公开地图数据，不含事件真相。 |
| SERVER_ONLY_events.json | 三幕、28 条证据与 12 个动作定义；含扩展/恢复用动作，需按 mvp_enabled 筛选。只给开发团队与权威状态机，不能整份作为玩家载荷或 LLM 上下文。 |
| 03_第一幕_检查站.png 至 05_第三幕_主桥.png | 三个关键事件区域特写。 |

移动请求应提交 **action_id**；服务端据事件定义执行整段路线。不要让客户端提交任意 route_id 越过剧情。标准参考局：任务 445 秒，另加 30 秒简报和 45 秒复盘，共 8 分 40 秒。这是设计参考，不是试玩统计。

## 版本与赛前素材

创建日期：2026-09-15。环境为虚构卡马尔地区，场景单位与道路耗时是美术和游戏设计值。地图几何、材质与道具通过本地程序构建，无外部模型或贴图依赖；最终 Blender 文字使用内置 Bfont。

原版 WADI / 07 已保存在相邻目录 `WADI07_原版归档`，原文件仍保留。新版没有覆盖原版。

本包包含剧透，应只供团队内部协作。是否可把赛前制作的模型、代码或 AI 辅助资产直接用于提交，仍须根据主办方确认的规则决定；现有公开页面尚未明确该项。
