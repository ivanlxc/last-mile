## 当前配置

密钥仅保留在项目根 `.env`，该文件权限为 0600，Git 排除检查通过。本文、报告和公开模板均不包含密钥。

```dotenv
MODEL_PROVIDER=openai
OPENAI_MODEL=gpt-5.6-luna
OPENAI_REASONING_EFFORT=low
AI_ADVISOR_TIMEOUT_MS=30000
AI_EVALUATOR_TIMEOUT_MS=45000
AI_ADVISOR_MAX_OUTPUT_TOKENS=2500
AI_EVALUATOR_MAX_OUTPUT_TOKENS=5000
```

这些是本次模型和游戏提示词的试玩配置，不是所有模型的通用推荐。省略四项运行限制时，代码继续使用此前的 8000/20000 毫秒与 1200/3000 输出 token 默认值。推理参数可省略；选用其他模型时需确认其参数支持情况。

每项作业最多两次实际发送，现有持久化次数账本继续生效。整体作业截止时间为两次单次超时加 2000 毫秒调度余量。本配置分别为 62 秒、92 秒；这不是预期等待时间。超时、限流、无效输出等依照既有规则明确回退，界面不能把离线模板标成实时模型分析。

本轮共进行了 **15 次真实生成发送**，包括前期调参与失败请求；最终配置的 6 次均成功。前期有两次达到旧超时限制；`reasoning=none` 曾在英文会话中输出中文，不能算作英文成功。随后增加错语种检测，并采用通过本次双语验证的 `low` 设置。少量样本不能推导成功率承诺、响应时间 SLA 或最终账单；超时请求也可能计费。

## 本轮代码改动

- 新增可选推理参数和有范围约束的运行限制，配置指纹包含有效设置、排除密钥。
- 强化可信会话语言指令。顾问摘要/理由、评价摘要/维度解释增加保守的中英文脚本检测；保留明确引用的玩家原话，不在生成后改写回答。该检测不是完整语言识别器，不保证所有字段的语言或语义质量。
- 无效结构、引用或语言输出进入原有一次修复机会，仍失败则明确回退，不无限重试。
- 作业截止时间与运行限制同步，显式重试不会绕过原有两次发送上限。
- 新增 `pnpm verify:model`：默认仅输出安全的配置摘要，**不发出模型请求**。只有显式 `--live` 才调用模型，使用合成输入，默认每个岗位一次发送。

如需主动重新进行付费验证：

```sh
pnpm verify:model --live --role=all --locale=en-US --attempts=1 --output=.local-artifacts/ai-live/manual-en.json
```

可将语言改为 `zh-CN`，岗位改为 `advisor` 或 `evaluator`。`--attempts=2` 允许原有修复流程再发送一次；默认一次的测试失败不意味着生产服务没有修复能力。报告只能写入 Git 排除的 `.local-artifacts/`。不要把真实密钥放在命令参数、截图、文档或 Git 提交中。
