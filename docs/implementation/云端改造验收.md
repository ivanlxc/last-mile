## AI 测试边界

本轮测试使用离线代理或受控协议替身，**真实模型发送为零**。真实入口进程测试使用假密钥并禁止模型网络请求。此前有限 OpenAI 接入结果见[真实模型接入验收](真实模型接入验收.md)，不将其扩大解释为本次云端完整局已验收。

公开部署模板使用 `MODEL_PROVIDER=openai`，在 Render 配置有效的服务器密钥和模型；云端入口拒绝 `offline`。顾问或评价失败时必须保留明确的回退提示。

## 首次上线发现：首页外部链接被误拦截

Render 初次部署 `bc0b75f` 成功后，直接 GET 首页和健康接口均为 200；带 `Sec-Fetch-Site: cross-site`、`Sec-Fetch-Mode: navigate`、`Sec-Fetch-Dest: document` 的正常首页跳转却返回 403。线上只读请求复现了从 Render View 或外部分享页面点击链接的失败。

修复仅允许云端 `/`、`/index.html`（含查询参数）的顶层 GET/HEAD 文档导航；Host、显式 Origin、API、跨站嵌入及本机模式限制保留。交接等待页使用相同规则；响应 Vary 包含相关 Fetch Metadata 与 Origin，避免缓存混用不同请求上下文。

- 生产构建与严格类型检查通过；78 项 HTTP、安全及交接相关测试通过。
- 原云端邀请/独立身份/本人历史浏览器流程通过。
- 新增真实浏览器与本机真实 HTTP 监听器的外部链接回归：实际收到浏览器的 `cross-site/navigate/document` 标记，成功显示邀请页，未签发玩家身份。该测试不拦截浏览器请求，不验证生产 TLS 或模型。
- 本轮未调用模型、未读取线上玩家存档；修复在 Render 重新部署后的线上验证另行记录。

## 保留的运行边界

- 单实例、单数据库引擎；最多 5 个活动局，不提供横向扩容或多人协作玩法。
- 浏览器身份有效期 14 天；不提供账户注册、跨设备同步或凭邀请口令找回旧身份。
- 平台重启会封存未完成的局为技术中断，保留记录，不能无缝续玩。
- 每人每日 3 局、全站每日 100 次实际模型发送、同时最多 2 个模型任务；次数限制不是美元账单上限。
- Render/Neon 的免费额度、休眠和冷启动仍会影响可用性；本轮没有购买资源。
