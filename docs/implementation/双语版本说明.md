# LAST MILE v0.2 · 中英文版本

## 使用方式

首次访问默认英文。标题页的 **English / 中文** 切换会保存到当前浏览器；之后按已选偏好打开，不随操作系统语言自动切换。

每局创建时确定语言。开始后，该局的情报、顾问和复盘使用同一种语言；刷新按服务器记录恢复。要体验另一种语言，在标题页选择后开始新局。切换界面语言不作为补充额度、重置计时或修改已有上传的方式。

## 本次范围

- 标题、教程、任务简报、三幕故事、人物对白、行动与调查界面。
- 三维地图说明、二维地图标签、时间单位、错误与状态提示、窄屏布局。
- 服务端公开情报卡、观察范围、路线说明、来源核验、公开日志、终局与导出。
- 离线顾问和评价模板；真实模型的可信系统指令指定本局输出语言。
- 玩家自述、自由输入的问题和引用原话保留原文，不由固定翻译词典改写。

两种语言使用相同的场景 ID、路线、资源账本、时间成本、证据解锁规则和隐藏分支。译文不会变成新的调查渠道，也不会给予英文玩家额外信息。

## 实现边界

前端采用项目内的类型化词条和 React 语言状态；故事有独立英文文本。后端只翻译已经获准公开或进入 Agent 上下文的字段。服务器上的完整剧情词典不发送到浏览器或模型。

公开契约作兼容扩展：Bootstrap 声明支持的语言和默认语言，SessionProjection 返回当前局语言。既有枚举、资源规则和所有权逻辑不因本地化改变。模型输入保持原有白名单与独立顾问／评价边界，引用与证据版本 ID 保持稳定。情报在生成时冻结为本局语言的版本，报告、上传快照、模型看到的正文及文本哈希一致；复盘导出先确定最终语言内容，再持久化和计算哈希。

完整故事作者资料见 `故事与关卡实装.md`；后续定向试玩部署、数据库和完整技术栈见 `部署方案与技术栈.md`。
