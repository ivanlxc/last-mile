# 地图主界面与英文语音试用版

2026-09-19。本轮范围为**电脑浏览器**，主语言为英文；中文保留作开发参考。本轮不做手机界面或手机兼容验收。

## 页面与操作

- 现有地图占据主画面，保留 2D、Three 3D、Unity、Blender 资产、车队移动和单手手势。切换视图时保留已经加载的 3D 实例。
- `Intel` 打开左侧情报与调查，`AI advisor` 打开右侧助手。一次展开一个侧栏；关闭助手保留文字草稿。侧栏打开时仍可用鼠标操作地图，手势暂时停用以免误触。
- 底部选择路线或等待，然后在底部确认区检查成本并确认。点击路线不会立即出发。决策备注收进可展开区域。
- `Mission` 收纳资源、累计用时、帮助和结束本局。没有整体倒计时；调查、等待和行驶仍有各自耗时。
- `Story` 按章节显示新内容标记，打开插画、叙述和无线电对白。英文场景加入贯穿旅程的乘员小细节，剧情氛围不会改变路线事实或裁决。

## 英文语音

打开 `AI advisor`，点击麦克风按钮，首次使用时允许浏览器访问麦克风。停止录音后最终识别结果进入可编辑草稿；玩家自行点击发送。录音最长 90 秒，关闭侧栏会停止录音并释放麦克风。

情报卡、来源弹窗、溯源信息、助手回答和故事有 `Listen`。长内容按段顺序朗读，保留来源、观察范围、不确定性和限制。新的朗读替换旧朗读；录音开始时停止朗读。朗读不会自动上传卡片或执行游戏行动。

2026-09-19 后续修正：显示 `Preparing audio…` 和真实播放秒数；浏览器阻止播放或超过 10 秒未启动时保留已生成音频，点击 `Play audio` 直接恢复，不重复合成。关闭面板、停止或开始录音仍会释放播放器。语音配置采用短期缓存，`Retry audio` 可重新检查服务，不再把一次不可用状态永久保留。内置浏览器的朗读已由玩家确认正常。

语音输入入口为 `AI advisor → Voice input`，停止按钮为 `Stop recording`。当前本地配置已启用；真实 Deepgram 往返复验用合成测试录音得到完整原句，约 3.3 秒内收到最终文字和完成通知。真人麦克风权限仍由玩家在首次使用时允许。

语音使用服务端 Deepgram 代理：Nova-3 英文识别、Aura-2 英文合成。密钥只在被 Git 忽略的根目录 `.env`，不进入前端。详细配置与接口见 [English speech](../speech-setup.md)。服务未配置或连接失败时仍可键盘输入和阅读文字。

## 环境音

顶部 `Sound off` 默认关闭。玩家点击后开启轻微风声、引擎声以及新报告/新章节的无线电提示。车辆行进时引擎音变化；录音或朗读时自动降低环境音，网页隐藏时静音。再次点击关闭；离开游戏释放音频资源。当前音效由 Web Audio 生成，不需要下载额外音频资产。

## 本地启动与试用

```sh
pnpm install
pnpm dev
```

访问 `http://127.0.0.1:5173/`，选择 English。建议用 1280×800 或更大的电脑窗口。本机 Unity Web 构建继续使用原有本地文件；新机器需遵循 [Unity 本地试用](Unity接入本地试用.md) 完成构建。

快速试用顺序：开始护送 → 切换地图 → 打开/关闭 Intel → 打开 AI 并录音 → 编辑后发送 → 朗读情报或故事 → 打开环境音 → 确认路线并观察车队移动。

## 验证边界

首版 TypeScript、生产构建和全部默认测试通过：382 项通过、21 项 PostgreSQL 环境相关测试跳过。手背手势与音频恢复修正后再次构建并全量测试：392 项通过、21 项跳过。实际桌面浏览器自动测试使用 Chromium；内置浏览器的朗读由玩家确认。

协议和浏览器测试使用本地替身验证录音终止、最终文本保留、错误恢复、音频互斥和长文本分段，不向真实服务批量发送测试。另已做一次真实 Deepgram 英文合成→PCM→流式识别往返，确认最终文本在结束通知之前返回。真人麦克风、房间噪声、个人口音和实际听感仍需玩家本机试用。

浏览器验收覆盖桌面布局、完整三关、调查/上传/助手/复盘、无限时长、手势、Unity 通信和真实 Unity 车队移动。历史发布文档中的手机截图属于旧版本，不代表本轮支持范围。
