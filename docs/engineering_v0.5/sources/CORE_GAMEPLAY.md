## 0. 一句话玩法

> 三个人指挥一支维和车队护送 20 名平民撤离。
> **两个人能查情报但看不见时间，一个人能决策但什么都查不到。**
> 他们共用一个 AI 参谋——而这个 AI 只知道他们告诉它的事。

## 1. 三个角色

| | 🛰 情报分析员<br>`INTELLIGENCE ANALYST` | 📻 现场联络员<br>`FIELD LIAISON` | 🎖 车队指挥官<br>`CONVOY COMMANDER` |
|---|---|---|---|
| **持有资源** | 卫星 ×2<br>无人机 ×3 | 当地机构 ×3<br>目击者 ×2 | 时间<br>最终行动权 |
| **情报来源** | 自己调查 | 自己调查 | **完全来自队友上报** |
| **情报性质** | 事实（可量化） | 说法（待验证） | 二手 |
| **专属能力** | 🛣 **通行性判定**<br>「这条路能不能走？」 | 🔗 **溯源追问**<br>「这话谁说的？」 | 🤖 **AI 通道**<br>「它为什么这么想？」 |
| **和 AI 的关系** | AI 的同类 | AI 的盲区 | AI 的唯一接口 |

### 设计原则：每人一把只有自己能用的钥匙

三个专属能力不是装饰，是**过关的必要条件**：

- **分析员的通行性判定不是一个按钮**，是卫星/无人机的天然独占范围。
  只有他能回答「桥断没断、路通不通」——联络员再怎么问村民也问不出结构完好这种结论。
- **联络员的溯源追问是一个按钮**，也是第二关唯一的解。
  「四条证据其实同源」这件事，卫星查不出、无人机查不出、AI 更查不出——
  只有跟人打交道的人能问出「我也是听老王说的」。
- 两人的独占性来自**数据的物理性质**，不来自按钮数量。

> **硬约束**：每一关都必须至少有一个环节，是「没有某个角色就过不去」。
> 在 8 分钟的游戏里，某个角色闲 2 分钟就是 25% 的时间在发呆。

## 2. 信息可见性矩阵 ⭐

**这是整个游戏最核心的一张表，也是服务端视图过滤（view filtering）的直接依据。**

| 信息项 | 分析员 | 联络员 | 指挥官 | AI |
|---|:---:|:---:|:---:|:---:|
| 卫星 / 无人机原始情报 | ✅ 全部 | ❌ | 仅收到上报的 | 仅收到上传的 |
| 当地机构 / 目击者原始情报 | ❌ | ✅ 全部 | 仅收到上报的 | 仅收到上传的 |
| **撤离倒计时** | ❌ | ❌ | ✅ | ❌ |
| **伤员状态** | ❌ | ❌ | ✅ | ❌ |
| 完整战术地图 / 车队位置 | ❌ | ❌ | ✅ | ✅ |
| 简化地图（仅自己可侦察的目标） | ✅ | ✅ | — | — |
| **AI 背景数据库** | ❌ | ❌ | 仅通过追问暴露 | ✅ |
| **AI 建议与置信度** | ❌ | ❌ | ✅ | — |
| **AI 判断依据** | ❌ | ❌ | ✅ | — |
| **证据溯源图** | ❌ | ❌ | ✅ | — |
| 自己的资源余额 | ✅ | ✅ | — | ❌ |
| 队友的资源余额（只有数字，无内容） | ❌ | ❌ | ✅ | ❌ |
| 结算 AAR 报告 | ✅ 全貌 | ✅ 全貌 | ✅ 全貌 | — |

> **指挥官能看到队友的资源余额数字**，否则他下指令是在瞎指挥。
> 但他看不到队友已经查到了什么——那必须靠上报或靠喊。
>
> **AI 背景数据库不单独占 UI**。指挥官点已有的 `[你为什么这么判断?]` 时，
> AI 会顺带列出它引用了哪几条背景数据。复用旧按钮，不加新组件。

## 2.5 三层信息漏斗 ⭐

**指挥官是漏斗的腰，不是漏斗的口。**

他确实是全队唯一的汇总点，但他收到的是**队友愿意给他的**，不是全部——
因为上报每关限 3 次，而队友能解锁的不止 3 条。

```
┌─ 情报池（数据库预置）───────────────────  一关约 8–10 条
│                                            全部真相都在这里
└──────────────┬──────────────────────────
               │  ↓ 队友花资源调查（分析员 5 次 / 联络员 5 次）
┌─ 已解锁 ─────┴──────────────────────────  实际查到约 5–6 条
│               分析员和联络员各看各的
└──────────────┬──────────────────────────
               │  ↓ 队友筛选上报（每人限 3 条）
┌─ 指挥官看到 ─┴──────────────────────────  最多 6 条
│               ← 「上帝视角」其实只到这一层
└──────────────┬──────────────────────────
               │  ↓ 指挥官筛选上传（限 5 条）
┌─ AI 看到 ────┴──────────────────────────  ≤ 5 条 ＋ 背景数据库
│               AI 的判断只基于这些
└─────────────────────────────────────────
```

### 三条由此推出的硬结论

**1. AI 最终看到的，大约是全部真相的一半。**

**2. 每一层损耗都是某个人的决定，没有一层是随机的。**

这是整个设计最重要的一条。因为它意味着**失败永远可归因**——
AAR 结算时能精确指出：「那条能翻案的情报，在第二层被联络员丢掉了」。
这是这个游戏最有教学价值的输出，前提是三层漏斗都真实存在。

**3. 如果指挥官真是上帝视角，第二层就塌了。**

他一旦能直接看到队友所有已解锁情报，联络员的「上报」就不再是决策，
只是一个多余的点击。**漏斗塌成两层，游戏少掉一整个维度。**

│   [ 🛰 卫星扫描 ]   [ 🚁 派遣无人机 · 30s ]   │

```

**按钮清单**

| 按钮 | 消耗 | 说明 |
|---|---|---|
| 🛰 卫星扫描 | 卫星 −1 | 覆盖广、准确，但数据有 10 分钟延迟 |
| 🚁 派遣无人机 | 无人机 −1、时间 −30s | 实时高清，但只能看一个目标点 |

> 🛣 **通行性判定**是分析员的专属**范围**而非按钮：
> 「这条路能不能走」这个问题，全队只有他能回答。
| → 上报 | 上报额度 −1 | 把该条情报推送到指挥官面板 |

### 3.2 现场联络员 `FIELD LIAISON`

```
┌─ 现场联络员 ──────────────────────────────────┐
│ 📻 当地机构 ●●●     👤 目击者 ●●              │
├───────────────────────────────────────────────┤
│ 无线电 / 现场记录                             │
│ ┌───────────────────────────────────────────┐ │
│ │ [当地机构] 我们认为可能只是燃油事故       │ │
│ │ [目击者 A] 爆炸前有辆白色皮卡开进去了     │ │
│ │ [平民]     大家在往北边跑…                │ │
│ └───────────────────────────────────────────┘ │
├───────────────────────────────────────────────┤
│ 可联络对象                                    │
│   ○ 村长办公室    ○ 当地警察                  │
│   ○ 目击者 A      ○ 市场摊主                  │
│                                               │
│   [ 📻 联络 ]    [ 👤 询问 ]                  │
│   [ 🔗 溯源追问：你这消息哪来的？ ]  ★ 专属   │
├───────────────────────────────────────────────┤
│ 我的情报                              可信度  │
│   · 当地机构 · 疑似燃油事故      ❓   [→ 上报]│
│   · 目击者A · 可疑白色皮卡       ❓   [→ 上报]│
│   · 平民 · 人群在向北撤离        ❓   [→ 上报]│
│                                  上报余额 3/3 │
├───────────────────────────────────────────────┤
│ ⚑ 指挥官请求：核实爆炸原因                    │  ← 非强制
└───────────────────────────────────────────────┘
```

**按钮清单**

| 按钮 | 消耗 | 说明 |
|---|---|---|
| 📻 联络 | 当地机构 −1 | 快，但信息可能不完整或过时 |
| 👤 询问 | 目击者 −1 | 第一手，但完全未经验证 |
| 🔗 溯源追问 | 当地机构 或 目击者 −1 | **专属**。查明一条情报的真实源头，`❓` → `✅ / ⚠️` |
| → 上报 | 上报额度 −1 | 同上 |

> **联络员的情报天生带 `❓` 标记。**
> 这是他和分析员最大的手感差异：分析员拿到的是**事实**，联络员拿到的是**说法**。
> 只有花掉一次溯源追问，`❓` 才会变成 `✅` 或 `⚠️`。

│   ● 当前位置 · 村庄入口      │ 危险 ▓▓▓▓▓▓▓░ 84%     │
│   ─ 路线 A · 村庄主路   ⛔   │                        │
│   ─ 路线 B · 河谷绕行 +3min  │ 判断依据 (3)           │
│                              │  ✓ 目击者 · 可疑车辆   │
│                              │  ✓ 无人机 · 异常移动   │
│                              │  ✓ 当地新闻 · 爆炸     │
│                              │ [ 🔍 证据来源图 ] ★    │
├──────────────────────────────┤                        │
│ 队友上报 (4)                 │ 追问                   │
│  □ [分析] 无人机·异常移动    │ [ 你为什么这么判断? ]  │
│  □ [分析] 卫星·10分钟前正常  │ [ 比较路线 A / B ]     │
│  □ [联络] 当地·疑似事故      │ [ 你最不确定什么? ]    │
│  □ [联络] 目击者·可疑皮卡    │ [ 现在最缺什么信息? ]  │
│                              │                        │
│  [ ↑ 上传选中项给 AI ]  2/5  │ ⚠ AI 尚未掌握 (2)      │
│                              │  · 卫星·10分钟前正常   │
│  队友余额 🛰2 🚁2 📻2 👤2    │  · 当地·疑似事故       │
├──────────────────────────────┴────────────────────────┤
│ 指令  [ @分析员 侦察… ]   [ @联络员 核实… ]           │
│ 行动  [ ▶ 继续前进 ]  [ ↩ 绕行 ]  [ ⏸ 原地等待 ]      │
└───────────────────────────────────────────────────────┘
```

**按钮清单**

| 按钮 | 消耗 | 说明 |
|---|---|---|
| □ 勾选情报 | — | 从队友上报列表中选择 |
| ↑ 上传选中项给 AI | AI 上下文额度（上限 5 条） | **AI 的判断只基于这 5 条** |
| 🔍 证据来源图 | — | 展开 information graph，看证据是否同源 |
| 你为什么这么判断？ | — | LLM 实时生成解释 |
| 比较路线 A / B | — | LLM 实时生成对比 |
| 你最不确定什么？ | — | LLM 实时生成 |
| 现在最缺什么信息？ | — | LLM 实时生成 |
| @分析员 / @联络员 指令 | — | **非强制**，只在队友面板高亮一个目标 |
| ▶ 继续前进 / ↩ 绕行 / ⏸ 等待 | 推进剧情 | 唯一改变游戏状态的行动 |

> **「⚠ AI 尚未掌握」这一块必须有。**
> 没有它，「AI 只知道你告诉它的」这条核心机制在界面上是隐形的——
> 玩家只会觉得「这 AI 有点笨」，而不会意识到是自己没喂。

## 4. 核心循环

### 4.1 流程图

```
        ┌──────────────────────────────────────┐
        │  阶段 0 · 事件触发                    │
        │  指挥官收到极少量初始信息：           │
        │   · 事件通报「前方发生爆炸」          │
        │   · 地图 + 路线选项 + 各自代价        │
        │   · AI 初判（基于背景数据库）62%      │
        │  ⏱ 倒计时开始跑                       │
        └──────────────┬───────────────────────┘
                       ↓
        ┌──────────────────────────────────────┐
        │  ① 指挥官分派（非强制）               │
        │     [@分析员 侦察…] [@联络员 核实…]   │
        └──────────────┬───────────────────────┘
                       ↓
        ┌──────────────────────────────────────┐
        │  ② 队友消耗资源调查                   │
        │     情报解锁到各自面板                │
        └──────────────┬───────────────────────┘
                       ↓
        ┌──────────────────────────────────────┐
        │  ③ 队友筛选上报（每人限 3 条）        │
        │     ↕ 全程可语音喊话，免费但会失真    │
        └──────────────┬───────────────────────┘
                       ↓
        ┌──────────────────────────────────────┐
        │  ④ 指挥官筛选上传（限 5 条）          │
        │     → AI 自动重算，置信度条变化       │
        └──────────────┬───────────────────────┘
                       ↓
        ┌──────────────────────────────────────┐
        │  ⑤ 指挥官追问 / 查看证据溯源图        │
        └──────────────┬───────────────────────┘
                       ↓
              ╔════════╧════════╗
              ║  还要再绕一圈吗？ ║  ← 真正的核心决策
              ╚════╤═══════╤════╝
          「不够」 │       │ 「够了」
                  │       ↓
                  │  ┌──────────────────────┐
                  │  │ ⑥ 行动               │
                  │  │  前进 / 绕行 / 等待  │
                  │  └──────────┬───────────┘
                  │             ↓
                  │      状态变化 → 下一关
                  │
                  └──→ 回到 ①
                       但时间更少了、资源更少了
```

> ⚠️ **这是一个有回路的循环，不是一条直线。**
> 玩家追问完发现信息不够，会再派队友去查、再上报、再上传、AI 再改口。
> 绕一圈的代价是时间在跑、资源在掉。
>
> 所以整个游戏最核心的决策点**不在「选哪条路」，而在「还要不要再查」**。
> 实现时不要做成一次性的线性流程。

### 4.2 实例：第二关 · 村庄爆炸

```
T+00  ▸ 三人同时收到：「前方发生爆炸，道路中断」
      ▸ 指挥官额外看到：伤员倒计时开始跳
      ▸ AI 基于背景数据库给出初判：「建议绕行 · 危险 62%」

T+05  ▸ 指挥官 [@分析员 侦察爆炸点] [@联络员 核实原因]
        —— 队友面板高亮，但不强制

T+10  ▸ 分析员 [🚁 派遣无人机 → 爆炸点]   消耗 1/3 + 30 秒
      ▸ 联络员 [📻 联络 → 村长办公室]     消耗 1/3

T+25  ▸ 联络员拿到「疑似燃油事故 ❓」→ 口头喊出来
      ▸ 指挥官：「等等，AI 说 62% 是人为」

T+40  ▸ 无人机回传「附近有异常移动」
      ▸ 分析员 [🛰 卫星扫描 → 路线 B] → 河谷桥梁结构完好

T+50  ▸ 两人各自决定上报哪几条（上报有余额）
      ▸ 指挥官收到 4 条，勾 3 条 [↑ 上传给 AI]

T+55  ▸ AI 更新：「建议绕行 · 危险 84%」
      ▸ 指挥官 [你为什么这么判断?]
        AI：「目击者和无人机互相印证…」
      ▸ 指挥官 [🔍 证据来源图] → 两条线收束到同一个点

T+70  ▸ 联络员 [🔗 溯源追问 → 目击者 A]
        「那辆皮卡你是亲眼看见的吗？」
        目击者：「是市场那边的人跟我说的。」
      ▸ 联络员喊：「他也是听说的！」

T+80  ▸ 指挥官决策
      —— 而这 80 秒里伤员倒计时已经跳掉了 1:20
```

## 5. 已决策事项

| # | 决策 | 结论 | 理由 |
|---|---|---|---|
| D1 | 指挥官是否有情报获取能力 | **完全没有** | 强制信息流经过人，让沟通成为玩法 |
| D2 | 队友能否看到倒计时 / 伤员状态 | **完全看不到** | 催促变成真实的信息传递；评审桌前戏剧张力最强 |
| D3 | 队友能否看到 AI Advisor | **完全看不到** | 见下方工程论证 |
| D4 | 上报机制 | **每关限 3 次** | 筛选压力明确，实现只需一个计数器 |
| D5 | 指挥官指令效力 | **非强制** | 「下达指令 ≠ 得到执行」正是官方挑战 ③ 的 `task delegation` 训练点 |
| D6 | AI 的基线知识 | **给背景数据库** | 开局 62% 有来源，不是瞎编；且历史数据 ≠ 当前情况，本身可成为陷阱 |
| D7 | 上传后 AI 是否自动重算 | **自动** | 置信度条会动，玩家能直观看到「这条被当成强证据了」 |

### D6 补充：背景数据库放什么

```
AI 的知识 = 背景数据库（固定）＋ 指挥官上传的情报（动态，≤ 5 条）
```

库里放**历史统计与区域档案**，每关 3–5 条，例如：

- 「该区域过去 30 天记录 3 起 IED 事件」
- 「主路在雨季有塌方史」
- 「本地机构上报准确率历史值 71%」

这样开局的 62% 有来源。**而且这个来源本身就可以有问题**——
历史数据 ≠ 当前情况。第三关可以专门做这个陷阱：
AI 因为「这条路历史上出过 3 次事」给出高风险判断，
但玩家调查后发现那三次是同一伙人干的，而那伙人上个月已被清剿。

**统计正确，推论错误。** 这比「AI 随机犯错」高一个量级。

### D7 补充：置信度条会动，是故意的

自动重算意味着玩家上传一条，62% → 84%，他立刻看到「这条被当成强证据了」。
这会诱导他去试探「喂哪条能让它更确定」——**这正是陷阱**。

第二关就是：喂得越多，AI 越自信，而它是错的。
**置信度上升 ≠ 判断变准。**
让玩家亲手把一个错误答案喂到 84%，比任何说教都有效。

### D3 的工程论证（队友不显示 AI 面板）

架构前提：**权威服务端 + 视图过滤**（server-authoritative + view filtering）。
服务端持有唯一 `GameState`，每个 client 只收到过滤后的视图。
D3 在工程上就是：`aiState` 字段是否进入另外两人的视图。

**不进入，省下四样：**

1. **LLM 延迟只影响 1/3 的屏幕** ← 最实际
   调一次 LLM 要 2–5 秒。只有指挥官在等，另外两人还在派无人机、问目击者——延迟被藏进别人的忙碌里。评审桌前直接可见。

2. **两块队友面板可以是同一个组件**
   分析员和联络员面板结构完全一致：
   `[资源余额] → [展示区] → [目标列表 + 调查按钮组] → [情报列表 + 上报]`
   一个 `InvestigatorPanel` + 两份 config 即可。估计省 3–5 小时前端。
   按钮组数量不同（分析员 2 个 / 联络员 3 个）由 config 驱动，不影响组件复用。

3. **故障隔离**
   LLM API 超时 / 限流 / 格式错必然会发生。只有指挥官依赖 `aiState`，另外两人的游戏继续跑。

4. **事件流只有一条线**
   AI 相关 socket 事件只在 `commander ↔ server` 之间，调试只盯一条线。

**代价与补偿：**

| 代价 | 补偿 | 成本 |
|---|---|---|
| 队友对「人机信任」主题感知变弱 | 结算 AAR 三人都看到全貌，含「你上报的那条导致 AI 判错」 | ~0（独立界面） |
| 队友不知道 AI 说了什么 | 指挥官会口头转述——**而转述必然失真**，这恰恰强化主题 | 0 |
