# PRD / 三关现场与尾声

版本：M1 三关增量；2026-09-22。上位体验设计见 [GDD](01_GDD.md)。本文件区分当前原型、完整切片与商业发行，避免混用验收标准。

## 1. 用户与目标

首批用户为团队和定向邀请的试玩者，仍为一人一局。希望验证“空间调查 → 证据判断 → AI 辅助 → 指挥行动”是否容易理解且有吸引力。商业目标用户暂按喜欢叙事调查/决策游戏的 PC 玩家假设，尚未通过市场验证。

M1 不改变现有线上入口、邀请码、会话隔离、默认语言、模型供应商或成本上限。E1、E2、E3 均提供现场入口；选择现场后，进入下一关会保留该模式并重置到新场景入口。

## 2. 已确认的规则约束

| 约束 | 明确行为 |
| --- | --- |
| 单人 | 其他岗位是游戏角色；不增加房间、多人同步或远程协作 |
| 真实世界隔离 | 隐藏 case、根来源和行动后果留在服务端 |
| 调查预算 | 卫星 2、无人机 3、机构 3、目击者 2，整局共享 |
| 报告预算 | 每岗位每关 3 条；简报、追加调查与溯源沿用现有规则 |
| AI 资料预算 | 每关 5 条不可变上传；读取、收取报告均不等于上传 |
| 时间 | 新会话采用 instant 动作结算；走动和思考没有隐性剧情耗时 |
| 结果与评估 | 后果由剧本规则决定，独立评估 Agent 读取受限行为事实 |
| 双语 | 英文默认；本局沿用创建时选定的英文或中文 |

## 4. 不在 M1 的功能

原生 Unity 第一人称构建、现场物件的权威观察 API、NPC 动画与自由对话、真实无人机驾驶、车辆驾驶、战斗、复杂寻路、20 名乘员演出、自动存档/跨设备恢复、账号支付、章节编辑器、角色与车辆动画演出尚未完成。当前已实现静态接收站尾声与公开行动结果提示。

## 5. M2 完整垂直切片需求

| ID | 需求 | 进入开发前必须补全 | 退出条件 |
| --- | --- | --- | --- |
| V01 | 三种可检视现场物件 | 每种物件的公开状态、观察条件、报告成本和变体映射 | 只根据解锁的观察生成报告，无前端预埋答案 |
| V02 | NPC 多轮调查 | 编排对白节点、回答范围、追问预算与同源线索 | 两种合理判断路径均可玩，不以固定按钮顺序通关 |
| V03 | 后果演出 | 将规则事件映射到镜头、车辆停靠/放行和字幕 | 演出重放不重复结算；跳过演出也不影响结果 |
| V04 | 两种信息变体 | 明确真相、公开观察、可辩护动作、来源传播图 | 玩家不能只记住“永远绕行/永远信 AI” |
| V05 | 本章复盘 | 行为时间线与展示/上传回执绑定 | 能说明每次决策时玩家和 AI 各知道什么 |
| V06 | 试玩与迭代 | 至少 5 位非开发者按一致脚本试玩 | 完成观察记录后决定继续生产或调整循环 |

20–30 分钟是 M2 的体验长度假设；禁止用 M1 自动化测试运行时间作为内容时长。首轮观察应记录实际时长、卡住的位置、是否需要提示、是否主动核查来源、是否能解释 AI 所见资料与自己所见资料的差别。

## 6. 非功能需求

- **安全**：不新增客户端密钥或私有剧情导入；视觉场景无案件输入。服务端仍检验身份、会话、epoch、版本、phase 与预算。
- **可靠性**：网络失败留在原确认界面；运输重试使用同一幂等键；资源以服务端投影为准。新视图不添加乐观扣费。
- **性能**：M1 性能目标为桌面浏览器 1080p 中等设备 45 FPS。2026-09-22 确认的原生精细样板以 Mac mini M4 / 16 GB 为基准，目标实际渲染分辨率 1080p、标准画质稳定 30 FPS；MacBook Pro M4 Pro / 24 GB 在相同分辨率下争取 60 FPS。两者均为待实测目标，不能作为已有结果或商业版最低配置。测量协议见 [设备与性能目标](art-direction/README.md#5-已确认设备与初步性能目标)。
- **可访问性**：文字可替代声音、快捷地点可替代行走；默认不摇晃镜头；旧 2D 地图仍可用。正式手柄/字幕大小选项留到平台输入工作项。
- **可维护性**：空间渲染和业务命令分离；业务只用 `game.command`；新增剧情不能写进 Three.js 或 Unity 脚本。
- **隐私**：M1 不收集路线移动遥测，不新增录音或第三方 SDK；普通游戏动作沿用既有日志。

## 7. 发布与回退

在 feature 分支验证、保留原地图入口。完成评审后才合并并触发现有 Render 部署；本次不更改生产数据库或密钥。M1 无 schema migration，回退前端提交即可回到原入口，已产生的报告和上传继续兼容。

商业版发布门槛另行制定，至少包含：真实存档恢复、内容版本锁定、离线产品选择、玩家数据处理、模型中断时可完成任务、模型费用归属、素材授权清单、目标硬件性能、发行安装包和崩溃恢复。以上是后续产品工程范围，不是本次已经通过的验收。
