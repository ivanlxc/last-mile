## 阶段与完成门槛

1. **M1 / 当前代码**：E1/E2/E3 可进入第一人称指挥点；N07 呈现终局接收站；移动、转向、碰撞；面对附近地点交互；简报、侦察确认、证据阅读与上传；AI 侧栏；路线决策回到现有流程；英中双语；WebGL 失败时仍可操作。
2. **M2 / 下一阶段**：把现场观察写成权威剧情内容；检视带时间和来源的物件；NPC 对话与证据绑定；两种剧情变体；看得见的路线后果；本章复盘。完成三层世界信息审计后才能称为完整垂直切片。
3. **M3 / Unity 切片**：搭建 1 米真实比例的场景，角色控制器、碰撞、交互、动画、音频混合、平台输入适配；对齐同一组公开投影与命令契约；在真实 Editor 和构建产物中验收。现有沙盘是战略地图，不直接放大成步行关卡。
4. **M4 / 商业生产基础**：存档与恢复、内容版本兼容、章节编辑工具、原生客户端 UI、离线策略、账号/付费权益与模型成本、发行构建和完整 QA。完成后再扩充章节，避免把未经验证的循环复制到整款游戏。

不以 AI 编程速度估算最终工期。每一阶段以可试玩的结果和退出条件安排后续工作。

## 已确认与待决定

**保留**：单人；其他岗位为游戏角色；20 名乘员；整局调查次数不重置；岗位每关 3 条上报；AI 每关最多 5 条上传；溯源与更正占新额度；隐藏真相和两个 Agent 分离；默认英文、可选中文。

**当前采用的实施假设**：M1 复用现有联网应用及真实模型接入配置；测试专用服务显式使用 offline 模板，避免调用付费 API。不会改动用户的 `.env` 或线上环境。

**2026-09-22 设备确认**：Mac mini M4 / 16 GB 为原生精细样板的首轮基准设备；MacBook Pro M4 Pro / 24 GB 为更高画质验证设备。macOS 是明确的样板验证平台。性能目标与测量协议见美术方案，尚未完成实际原生构建性能验收。

**待产品决定**：商业版是否必须断网完成主线。这会决定权威规则是否需要可独立运行的本地内核。M1 不依赖这个答案，M4 之前必须确认。目标平台、商业模式、预算和演出规模在切片试玩反馈之后定案，不据此购买服务或素材。

## 环境限制

本机 `node scripts/build-unity.mjs --check` 未找到 Unity Editor。先以 Three.js 制作可验证的交互原型，继续保留 Unity 为后续正式场景制作方向。需要安装项目指定 Editor 与 Web Build Support，并由账号持有人完成授权后，才能进行真实 Unity 编译和运行测试。不能用旧版 Unity 发布包或浏览器协议桩替代新场景验收。
