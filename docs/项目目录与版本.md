# 项目目录与版本

整理日期：2026-09-16。

## 开发入口

项目仓库：[ivanlxc/last-mile](https://github.com/ivanlxc/last-mile)。`origin` 指向该仓库；使用 `git clone https://github.com/ivanlxc/last-mile.git` 获取。

`<repository-root>` 指各成员克隆到的本机目录，没有必须使用的个人绝对路径。后续源码修改、启动命令、API 配置和 GitHub 同步均在自己的仓库根目录进行。运行必需文件已全部位于此处，不依赖 Codex `outputs/` 或 `work/` 中的副本。已有全局 Node / pnpm 安装是开发工具，不是另一份项目源码。

## 版本如何读

- **游戏 v0.2.0** 是目前可运行的双语软件版本，见 `package.json`。
- **工程设计 v0.5** 是 PRD / HLD / LLD 的版本；它不是游戏 v0.5。
- **地图 LAST_MILE_v2** 是资产迭代编号；它不是当前软件主版本。
- `docs/engineering_v0.5` 保留原工程基线，并已包含双语兼容契约增补。该目录原 `MANIFEST.sha256` 是当时的基线校验，不是整个现有仓库的最新清单；见其 `README.md`。
- 发生差异时，结合当前代码、测试、`docs/implementation/实施与设计映射.md` 判断实装行为，不把历史稿和当前规则拼接使用。

## 外部 Codex 目录是什么

原开发机的 Codex `outputs/` 保存各阶段静态交付快照，用于保留此前的聊天链接；这是仓库之外的本机历史资料，不是团队需要建立的目录，也不是开发分支。

同级 `work/` 是历史中间稿、生成器、测试截图、浏览器缓存及临时依赖，不同步进 GitHub。独有的交付资料和有保存价值的地图／打包脚本已收回本项目。运行代码中间稿不覆盖当前已合并的实现。

未来临时文件、备份、ZIP 放项目自己的 `.local-artifacts/`；更新后的长期说明放 `docs/`。代码与资产的唯一维护位置就是当前仓库。
