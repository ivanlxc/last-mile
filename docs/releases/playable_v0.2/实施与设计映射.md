## 实装选择

1. **模块化单体。** 一台电脑运行 Node 24、Fastify 和 SQLite，React + Three.js 在浏览器呈现。世界推进、AI 调用、评价各有独立输入边界；没有因为“多个 Agent”而增加无必要的分布式服务。
2. **保留35表数据库规范。** 将其作为初始化SQL执行。追加 `runtime_schema_migrations` 版本记录以及 `runtime_session_meta`、`runtime_display_bindings`、`runtime_export_artifacts` 三张辅助表。正式证据、账本、事件、报告、上传、决策、manifest、job/attempt 和seal仍写入原规范化表。`world_state_json` 为服务端恢复快照，永不通过API返回。
3. **导出存SQLite。** 本版复盘JSON体积有限，直接持久化到SQLite，由授权API返回；没有开放任意文件下载或服务器路径参数。
4. **保留design_preview。** 用户授权开始实现，但未要求改变游戏数值审批状态。`approved_play` 尚不启用，当前全流程使用参考规则，适合内部试玩及hackathon原型验证。
5. **原生供应商适配。** 用 fetch 接入两家原生接口，不要求另搭一层通用网关。供应商输出语法使用共同可支持的子集；本机仍完整验证schema、引用、角色、上下文和预算。内部以 `StructuredProvider.generate` 对接核心 `AgentGateway`，替代设计包中仅作参考的 `modelAdapter.ts` 网关实现；公开 Agent 输入/输出与 HTTP 契约未改。
6. **两种观察记录。** 普通报告/建议须实际可见至少550ms才发回执。成本与渠道限制有专门界面，完整区块可见98%达550ms才发context回执。看到不等于理解；没有回执则评价保守处理。
7. **正面呈现限制。** 三维沙盘使用原GLB公开地图；提取原模型中的三辆车，随服务器位置移动，路线按实际waypoint弧长插值，车队尾随仅为画面表现。卫星等调查结果仍以已著作的证据卡交付，场景插画不充当侦察事实。
8. **无虚构交接。** 当前剧本在N07抵达时结束，沿途手续齐备与完整人员交接分开。没有handoff动作，因此不写入交接完成时间。
9. **停止与恢复。** 优雅关闭先处理采样时刻已到期的事件，再封存仍活动的局；意外重启按持久状态技术封存。终局历史可通过显式本地启动授权重新读取，不能恢复对过去时间线的指挥权。
10. **手工行为注释。** 记录理由、是否考虑限制、是否比较成本以及研究问题都由玩家主动填写。没有让语言模型“猜测”玩家动机，也没有替玩家自动勾选校准信任。

## 美术与叙事

- `client/src/lib/narrative.ts`：完整公开开场、四步教程、人物对白和三幕描述。
- `docs/implementation/故事与关卡实装.md`：含私有分支的作者剧本，不对浏览器发布。
- `client/public/assets/map.glb`：复用用户已有 Blender 地图。
- `client/public/assets/{hero,gate,market,bridge}.png`：使用内置 image_gen 生成的二维场景。提示词记录在 `art-prompts.json`；没有通过用户模型API密钥付费调用生成。
- 当前内容是虚构的人道护送环境，不使用现实行动坐标或现实作战计划。

## 仍需实际产品验证

这些工作与当前代码是否可运行是不同的验收项：

- 用户配置具体模型后，在自己的账户验证权限、结构化输出兼容性、延迟与引用质量；本轮没有真实付费调用。
- 用没有看过剧本的团队成员做完整试玩，评估十分钟窗口、读取时间、渠道额度及新手引导压力。
- 用目标比赛机器实测3D帧率和启动速度；当前提供二维回退，没有宣称所有设备都达60fps。
- 复盘规则尚未经过心理测量或学习效果研究验证；它们只描述本局可观察行为。
- 当前没有完整人员交接关、跨启动历史列表、音频配音、英文完整本地化或公网部署。上述未纳入此版的实现完成声明。
